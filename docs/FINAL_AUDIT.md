# PULSAR — результат технического аудита

Дата проверки: 2026-10-27.

## Проверено локально

- Компиляция модулей `app/*.py` и `app/payments/*.py`.
- Автоматические тесты: 42 passed.
- Тесты изолированного кошелька сообщества, экономики, коллекций, модерации, подписей платежных webhook, диагностики и теперь временных рейтингов активности.
- Архив выпуска исключает `.env`, `.venv`, SQLite-файлы, кэш Python и тестовый кэш.

## Исправлено в этой ревизии

- `топ неделя` / `топ недели` считают реальные сообщения за последние 7 суток.
- `топ месяц` / `топ месяца` считают реальные сообщения за последние 30 суток.
- Добавлен журнал активности по группе с Unix timestamp и индексом для запросов периода.
- Добавлены варианты `топ весь`, `топ вся`, `топ все` для общего рейтинга по коинам.
- Уточнена документация: историческая активность до установки журнала не восстанавливается задним числом.

## Ограничения, которые остаются

- Тесты выполнялись локально, без подключения к Telegram, платежному API или реальной группе.
- Недоступность сети к Telegram / платежному провайдеру невозможно исправить одним изменением Python-кода; проверять нужно сетевой доступ с машины запуска.
- Telegram Bot API не даёт боту полный список всех участников группы; массовый созыв ограничен известными участниками и возможностями API.
- Старые пользовательские базы и `.env` не включены в архив. Перед запуском нужно сохранить и перенести именно рабочую базу и конфигурацию.
- Временные рейтинги считают сообщения, а не заработанные коины. `топ` без периода по-прежнему сортирует текущие коины сообщества.

## Дополнительное исправление после аудита

- Автоматические AI-мемы больше не должны случайно перехватывать известные текстовые команды (включая `топ неделя`, `профиль`, `играть`, команды модерации и созыв) до того, как обработчик команды сможет ответить. Это важно, поскольку автоответчик проверяется раньше некоторых текстовых веток.
- Добавлен список известных коротких команд-исключений рядом с автоответчиком; при добавлении новых команд его нужно обновлять.
