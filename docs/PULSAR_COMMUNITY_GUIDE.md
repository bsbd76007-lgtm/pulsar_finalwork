# PULSAR — помощник Telegram-сообществ

Бот объединяет социальные функции для групп и существующие личные функции казино. Казино-механики, ставки, пополнения, выводы и платежи оставлены отдельными от валюты сообщества.

## Подключение

1. Добавьте бота в группу.
2. Выдайте только необходимые права. Для `/mute` и `/ban` необходимо право ограничивать участников; для удаления сообщений требуется право удаления сообщений. Не выдавайте право добавлять администраторов без отдельной необходимости.
3. Когда бот становится администратором, он отправляет стартовое сообщение с инструкциями. Это событие Telegram Bot API `my_chat_member`; бот не может сам назначить себе права.
4. Если сообщение не пришло, проверьте, что бот не был добавлен ранее администратором, что обновления Telegram доходят до процесса и что бот может отправлять сообщения в группу.

## Личка

- `/start` — меню
- `/help` — справка
- `/profile` или `профиль` — профиль
- `играть` — меню игр
- `пополнить` — пополнение если пополнение настроено
- `вывести` — меню вывода, если доступно
- `кошелёк` / `баланс` — баланс казино

## Группа: модерация без слеш-команд

Администратор группы отвечает на сообщение нарушителя и отправляет обычный текст — без `/`. Проверяется текущая роль отправителя через Telegram, поэтому способ доступен владельцу и пользователям, которым выдали права администратора.

- `бан` — заблокировать участника; можно дописать причину: `бан спам`
- `разбан` — снять блокировку (ответом на сообщение заблокированного участника)
- `мут` или `мут 20д 2ч причина` — запретить отправку сообщений на указанное время; поддерживаются дни (`д`), часы (`ч`) и минуты (`м`), максимум 30 дней
- `размут` — снять ограничения
- `варн причина` — выдать предупреждение; три предупреждения вызывают автоматический бан. `репорт причина` — пожаловаться на сообщение администраторам
- `/chatstats` — статистика группы

Боту нужны права администратора на блокировку/ограничение участников. Автобан по трём предупреждениям включён по умолчанию. Проверьте поведение в тестовой группе.

## Группа: роли модераторов и созыв всех участников

Команды вводятся без `/`. Назначение и снятие роли выполняется ответом на сообщение участника:

- `повысить 1`, `повысить 2`, `повысить 3`, `повысить 4` — назначить уровень модератора; можно указать права через запятую, например `повысить 3 warn,mute,call`.
- `понизить` — снять роль; `модеры` — список назначенных ролей.
- `кал`, `калл`, `созыв`, `созвать всех`, `все сюда` — срочный созыв группы. Созывать может администратор Telegram или модератор с правом `call`.

Созыв работает через отдельный модуль `app/group_call.py`: бот отмечает участников, чьи сообщения он видел, и упоминает сохранённый список в нескольких сообщениях. **Полный список всех участников через Telegram Bot API недоступен**: молчащие/неизвестные участники не могут быть гарантированно отмечены. Бот должен иметь доступ к сообщениям группы.

## Группа: экономика и коллекционирование

Все данные привязаны к ID группы, поэтому у каждого чата своя экономика.

- `экономика чата` или `помощь чата` — справка
- `собрать` — найти карту текущего события раз в 2 часа; `собрать ресурс` — обычный ресурс раз в 4 часа
- `инвентарь` — список предметов
- `магазин` — цены
- `купить дерево 2` — купить предметы за коины
- `продать рыба 3` — продать предметы из инвентаря
- `коины` — баланс коинов и опыт
- `ежедневный бонус` — награда раз в сутки
- `топ чата` — рейтинг по коинам и опыту
- `играть` или `игры чата` — справка по групповым мини-играм
- `орёл` / `решка` — монетка: угадал — +3 коина, не угадал — попытка стоит 1 коин (ниже нуля баланс не уходит)
- `камень` / `ножницы` / `бумага` — дуэль с ботом, победа даёт 5 коинов
- `викторина` — общий вопрос; первый правильный ответ получает 8 коинов
- `угадай число` — общий раунд с числом от 1 до 5; победа даёт 10 коинов

Предметы: дерево, камень, рыба, кристалл, корона. Десятое учтённое сообщение начисляет небольшой бонус активности; избегайте искусственного спама ради фарма.

## Игры

В группах доступны без денежных ставок мини-игры `орёл`/`решка`, `камень`/`ножницы`/`бумага`, `викторина` и `угадай число`. Ответы на общую викторину и загадку принимаются в порядке поступления; в каждой группе одновременно действует один общий раунд каждого типа. Состояние активного раунда хранится в памяти процесса и сбрасывается при перезапуске бота. Дополнительно доступны Telegram-броски `/dice`, `/football`, `/basketball`, `/darts`, `/bowling`. Личные денежные ставки используют существующий баланс казино, а коины сообщества не конвертируются в денежный баланс.

## Premium custom emoji

Файл `assets/emoji_catalog.json` содержит каталог исходных ID пользовательских Telegram-эмодзи, присланных владельцем, и fallback-глифы. Telegram может показывать обычный символ вместо кастомного эмодзи, если идентификатор недоступен для конкретного сообщения или клиента. Кастомные эмодзи используются через HTML-тег `<tg-emoji emoji-id="...">...</tg-emoji>`.

## Хранение и запуск

SQLite-файл по умолчанию — `pulsar_fan.sqlite3`; `PULSAR_DB_PATH` может переопределить путь. Секреты из `.env` не следует помещать в ZIP или коммитить в Git.

```bash
python3 -m pip install -r requirements.txt
python3 -m app.bot
```

Для постоянной работы используйте менеджер процессов, например systemd, и отдельного непривилегированного пользователя ОС.

## Известные ограничения

Это не полная копия Iris. В текущем коде нет гибкой панели конфигурации, автомодерации всех видов спама/ссылок, приватных торгов между игроками, репутации/закладок/каталогов и веб-дашборда. Некоторые права Telegram требуют ручного предоставления; бот не может обходить настройки приватности или права администраторов.

## Поддержка бота через Telegram Stars

В личном меню есть кнопка «Поддержать бота». Пользователь выбирает 25, 50, 100 или 250 Telegram Stars и подтверждает встроенный счёт Telegram. Обработчики проверяют payload на этапе pre-checkout и подтверждают успешный платёж сообщением. Пожертвования не зачисляются на игровой баланс и не дают игровых преимуществ. Для этого способа не нужен платёжного API-токен; Telegram обрабатывает оплату Stars.

## Оригинальная игра: Мир районов

Это отдельная социальная RPG для групп, не казино и не реальные денежные ставки. В каждом чате действует одно случайное событие на 24 часа: «Мусорный рейд», «Ночь неона», «Дождь коинов», «Охота за легендой» или «Дворовый турнир». Событие сохраняется в SQLite, одинаково для участников конкретного чата и меняется по истечении суток.

- `мир` / `ивент дня` — активное событие и таймер до смены.
- `поиск в мире` — найти карту и заработать коины; кулдаун 30 минут на игрока в рамках текущего события.
- `альбом` — коллекция из шести карт разной редкости.
- `пак карт` — купить три случайные карты за 35 коинов.
- `рынок карт` — посмотреть редкость и цену продажи.
- `продать карту дворовый_кот 1` — продать карту по её цене.

Повторы можно продавать, редкие карты дороже. Коины, карты и события хранятся отдельно от денежного баланса казино и платёжного сервиса. События и коллекция переживают перезапуск бота.

## PULSAR: бесплатные команды обычными словами

Имя бота в интерфейсе — PULSAR. Все перечисленные ниже возможности доступны без платной подписки; Telegram API и права самого Telegram всё равно ограничивают некоторые действия.

В группе можно написать без `/`:
- `мой id` — Telegram ID пользователя и ID чата;
- `админы` — список администраторов;
- `правила` — прочитать правила;
- `правила установить текст правил` — сохранить правила (администратор);
- `приветствие установить Привет, {name}! Добро пожаловать в {title}` — задать приветствие (администратор);
- `заметки` — список заметок; `заметка название` — показать заметку;
- `антиссылки вкл` / `антиссылки выкл` — включить или отключить удаление ссылок;
- `антифлуд вкл` / `антифлуд выкл` — включить или отключить защиту от флуда;
- `фильтр ключевая фраза => ответ бота` — добавить автоответ (администратор);
- `удалить фильтр ключевая фраза` — удалить автоответ (администратор).

Модерация по ответу на сообщение: `репорт причина` доступен участникам; `мут 20д 2ч спам`, `бан причина`, `варн причина`, `размут`, `разбан` — только администраторам группы. Единицы времени: `д`, `ч`, `м`.

## Важное уточнение о функциях Iris

Это самостоятельная реализация бесплатных аналогов распространённых функций ботов-помощников: модерация, репорты, предупреждения и журнал, приветствия, правила, заметки, фильтры, антиссылки, антифлуд, очистка, статистика, экономика, игры и недельный глобальный рейтинг. Это не буквальный перенос всех функций, исходного кода или внутренних платных сервисов Iris. У Iris много постоянно меняющихся модулей и интеграций; этот проект не заявляет о полном функциональном паритете. Перед включением защиты проверьте её в тестовой группе и убедитесь, что бот получил необходимые права.


Подробная актуальная инструкция для администраторов и модераторов группы: [`PULSAR_GROUP_GUIDE.md`](PULSAR_GROUP_GUIDE.md).
