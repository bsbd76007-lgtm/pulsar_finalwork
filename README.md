# PULSAR • Telegram community bot

## Запуск

1. Создайте `.env` рядом с `app/` и укажите `BOT_TOKEN=...`.
2. Установите зависимости в виртуальное окружение: `python -m pip install -r requirements.txt`.
3. Запустите `python -m app.bot`.

## DeepSeek AI

```env
PULSAR_AI_API_KEY=your_deepseek_api_key
PULSAR_AI_BASE_URL=https://api.deepseek.com
PULSAR_AI_MODEL=deepseek-chat
```

PULSAR использует DeepSeek для разговорных ответов. В группах, где бот получает сообщения, он сохраняет короткий общий контекст публичных сообщений в SQLite (`pulsar_ai_memory.sqlite3`) и может учитывать недавние сообщения из других групп. Личные чаты в эту память не записываются. Не включайте эту функцию в группах, где участники не согласны с обработкой их сообщений; храните файл памяти в защищённом каталоге. Очевидные токены, пароли и длинные числовые секреты отфильтровываются, но это не заменяет согласие участников и правила хранения данных.

## Игры и платежи

Игры используют Telegram dice-анимации и внутреннюю игровую базу. Перед включением реальных платежей проверьте `PAYMENTS_ENABLED`, настройки платёжного сервиса и сетевое соединение. Не запускайте два экземпляра одного Telegram-бота одновременно: это вызывает конфликт polling.

## Игры сообщества и события

Игры чата используют отдельные коины сообщества (не USD/USDT и не выводятся):
- `монетка орёл 5` / `монетка решка 5` — ставка 1–1000 коинов;
- `кости 5` — ставка на бросок кубика;
- `слоты 5` — три символа, выигрыш зависит от комбинации;
- `камень`, `ножницы`, `бумага` — дуэль без ставки;
- `викторина` или `угадай число` — командные быстрые раунды;
- `ежедневный бонус`, `топ чата`, `игры чата`, `ивент` — награды, рейтинг, справка и текущее событие.

Событие мира хранится в SQLite и меняется раз в 24 часа. Отдельные события теперь меняют шансы выпадения карт, а не только описание. Игровые команды работают в группах, где бот может читать сообщения. Денежные ставки казино остаются отдельной системой и не смешиваются с коинами сообщества.

## Casino games and daily events

Casino is a separate private-chat section from community coins/cards. Available game commands are `/dice`, `/football`, `/basketball`, `/darts`, `/bowling`, `/billiards`, `/roulette`, `/blackjack`, `/baccarat`, `/crash`, and `/mines`; the inline Games menu is the primary launcher. Bets use the configured account USD balance and are recorded in the SQLite wager ledger. The shared Casino Event rotates daily by UTC date and applies a small multiplier bonus to winning rounds of the featured game. Review applicable local laws, age restrictions, responsible-play requirements, and payment-provider rules before enabling real-money deposits or withdrawals. Never expose API tokens or database files in a public archive.


## Отдельная скретч-карта и социальные функции сообщества

Эти возможности работают отдельно от казино и его денежного баланса. Скретч-карта использует только **коины сообщества** в `community_store.py`; она не вызывает `place_bet` и не меняет кошелёк казино. На одного участника в одном чате действует пауза 5 минут. Награда случайная: 0, 3, 7, 15 или 40 коинов.

### Команды без `/`

- `скретч` — стереть скретч-карту; повторный запуск доступен через 5 минут.
- Ответом на сообщение: `жениться` / `выйти замуж` / `предложение` — создать брак в пределах текущей группы. Один участник не может иметь два брака в этой группе.
- Ответом на сообщение супруга/супруги: `развод` — расторгнуть брак в данных этой группы.
- `семья` / `моя семья` — показать партнёра, детей и родителей.
- Ответом на сообщение: `усыновить` / `удочерить` — добавить участника как ребёнка в семейную карточку.
- Ответом на сообщение: `поцелуй`, `поцеловать`, `обнять`, `обнимашки` — лёгкая ролевая реакция.
- Ответом на сообщение: `секс` — только не-графическое романтическое ролевое приглашение; оно не означает согласия адресата, отказ всегда допустим.
- Ответом на сообщение: `сюрприз` / `приготовить сюрприз` — ролевая реакция с подарком.

Все отношения хранятся отдельно для каждого чата: брак в одной группе не становится браком в другой. Для команд с адресатом нужно использовать **ответ на сообщение** — это не зависит от username и работает даже у участников без публичного ника. Сейчас функции ориентированы на групповые чаты и не являются юридическими или реальными отношениями.

## Local diagnostics

Администратор, указанный в `ADMIN_TELEGRAM_IDS`, может вызвать `/healthcheck`. Команда проверяет наличие основных файлов, 20 карточек социальных действий, доступность Python-зависимостей, наличие настроек платежей/ИИ и целостность доступных SQLite-баз (`PRAGMA quick_check`). Она не обращается к внешним API и не доказывает, что Telegram, DeepSeek или платёжный сервис доступен по сети. TON-депозиты остаются отключёнными, пока не будет подключена доверенная проверка транзакций.

## Обновление: коллекционные карточки и визуальные ответы

- Интерфейс карточной игры находится в `assets/community_cards_interface.png` и прикрепляется к сообщениям альбома, рынка, открытия пака и найденной карты.
- Социальные команды в группах отправляют соответствующую карточку из `assets/social_cards/` как фото с подписью и ответом на исходное сообщение: поцелуй, объятия, брак/предложение, развод, семья/дети/родители, усыновление, цветы, сюрприз, свидание, признание, поддержка, флирт и другие действия.
- В личке: `сообщество` открывает центр коллекции; `собрать` / `поиск в мире` ищет карту; `пак карт` открывает 3 карты за 35 коинов; `альбом` показывает коллекцию; `рынок карт` показывает цены; `продать карту дворовый_кот 1` продаёт одну карту; `правила коллекции` показывает инструкцию.
- Карточная экономика использует только коины сообщества и отдельна от денежного баланса казино. Карты в текущем интерфейсе показаны через тематическую иллюстрацию; индивидуальные портреты каждой карты не генерируются автоматически.
- В группах бот должен быть участником чата. Чтобы ответы с фотографиями работали, ему нужны обычные права отправки сообщений и фотографий.

## Производительность и бесплатные функции сообщества

### Ускорение SQLite

Хранилище сообщества использует WAL, `busy_timeout`, `synchronous=NORMAL`, временные таблицы в памяти и индексы для недельного рейтинга, журнала модерации и активности. Инициализация схемы кешируется на время процесса для каждого пути базы, поэтому бот больше не выполняет `CREATE TABLE IF NOT EXISTS` на каждом сообщении. При смене `PULSAR_DB_PATH` новая база инициализируется отдельно.

### Функции в духе Iris — доступны в PULSAR без подписки

По публичным материалам Iris в Telegram у сообщества упоминаются премиум-возможности вроде пользовательского префикса, никнеймов/званий/описаний и ограничений на стикеры или КАПС. В PULSAR не копируется чужой код или закрытая реализация; ниже указано, что есть сейчас, а что требует отдельной реализации:

- Уже доступны бесплатно: модерация (варн/мут/бан), журнал модерации, правила и приветствия, заметки, фильтры автоответов, анти-ссылки, антифлуд, очистка сообщений, жалобы, статистика и недельный рейтинг активности.
- Уже доступны бесплатно: экономика сообщества, ежедневная награда, предметы, коллекционные карточки и паки, события, социальные действия с карточками и профиль.
- Не объявляются готовыми, пока не реализованы и не покрыты тестами: произвольный префикс для всех команд, пользовательские звания/описания профиля, автоматическое ограничение стикеров/КАПС по настройкам, полноценная система пользовательских алиасов команд и импорт/экспорт всей конфигурации группы.

Все игровые коины сообщества отделены от денежного баланса казино. Функции, зависящие от Telegram API или внешних сервисов, должны проверяться в тестовой группе после развёртывания.

## Дополнительные бесплатные функции групп

- `ник текст`, `титул текст`, `о себе текст` — локальный профиль участника в текущей группе.
- `мой профиль сообщества` / `мой уровень` — уровень, XP, сообщения и коины сообщества (не баланс казино).
- `префикс !` — задать групповой текстовый префикс; `префикс выкл` отключает его. Команды с префиксом обрабатываются как обычные текстовые shortcuts.
- `/anticaps on|off` — удаление сообщений с 75%+ заглавных букв (минимум 12 букв).
- `/antistickers on|off` — удаление стикеров у обычных участников.
- `экспорт настроек` — показать JSON-бэкап настроек, заметок и фильтров; `импорт настроек {JSON}` — восстановить их. Импорт только для администраторов и ограничен сообщением Telegram.
- `команда создать привет => Добро пожаловать!` и `команда удалить привет` — пользовательские команды/автоответы на уровне группы; встроенные команды имеют приоритет.
- `запретить слово слово`, `разрешить слово слово`, `запрещённые слова` — фильтр слов; совпавшее сообщение участника удаляется, администраторы не затрагиваются.
- `мои предупреждения` / `мои варны` — показать последние предупреждения участника.

Анти-CAPS и антистикеры по умолчанию выключены, а фильтр запрещённых слов активируется только после добавления хотя бы одного слова. Перед включением защиты убедись, что у бота есть право удалять сообщения.

## Global community update (text-first)

This release adds a text-only help command (`помощь сообщества`) and administrator text aliases for group rules, welcome/goodbye templates, and keyword-filter management. All these aliases are used without `/` in groups. Profile customization and profile cards remain per-chat; community coins are kept separate from the casino wallet.

### New text commands
- `помощь сообщества`
- `задать правила <текст>`
- `задать приветствие <шаблон>` and `задать прощание <шаблон>` (variables: `{name}`, `{title}`)
- `включить приветствия`, `выключить приветствия`, `включить прощания`, `выключить прощания`
- `добавить фильтр <фраза>`, `удалить фильтр <фраза>`, `список фильтров`

Group-setting commands require administrator permissions. Before production deployment, test these flows in a private test group and keep backups of `.env` and the SQLite database. `first_seen` in profile cards is the first message observed by the bot, not the actual Telegram join date.


## Созыв всех участников группы

Отдельный модуль `app/group_call.py` ведёт список участников, чьи сообщения бот уже видел в каждой группе. Вызвать созыв может администратор Telegram или назначенный модератор с правом `call`. Команды без `/`: `кал`, `калл`, `созыв`, `созвать всех`, `все сюда`. Бот публикует срочное сообщение и упоминает сохранённых участников порциями, чтобы не превышать лимит Telegram.

**Ограничение Telegram Bot API:** бот не может запросить полный список всех участников обычной группы. Поэтому созыв охватывает участников, которые уже писали в группе после установки этой функции и чьи сообщения доступны боту. Молчащие участники, о которых бот не знает, автоматически добавлены не будут. Чтобы расширить список, включите доступ бота к сообщениям группы и дайте участникам написать хотя бы одно сообщение. Реальная доставка уведомлений зависит от настроек Telegram пользователя.

## PULSAR feature artwork

Feature illustrations are stored in `assets/feature_cards/` and sent as separate image messages immediately before the matching text/menu. The card set includes profile, games, wallet, withdrawal, chat/week/month/all-time leaderboards, community, commands, moderation, rules, support, statistics, collections and group play. Missing artwork is logged and does not prevent the text response.


### Рейтинги чата

- `топ` / `топ чата` — текущий рейтинг по коинам сообщества.
- `топ весь` / `топ вся` / `топ все` — общий рейтинг чата по коинам.
- `топ неделя` — активность за последние 7 суток по сообщениям, записанным ботом.
- `топ месяц` — активность за последние 30 суток по сообщениям, записанным ботом.

Исторические сообщения до включения журнала активности не восстанавливаются задним числом.


## Автоматические реакции в группах

PULSAR иногда самостоятельно подхватывает контекст беседы и отвечает мемной репликой — отдельные слова-команды для шуток не нужны. Настройка и ограничения описаны в [`docs/AI_AUTOREPLY.md`](docs/AI_AUTOREPLY.md). Для работы требуется `PULSAR_AI_API_KEY`.


## PULLSAR chat cards and live rankings

The private bot menus use the separate dark neon PULLSAR card assets in `assets/feature_cards/`. Group chat ranking commands (`топ чата`, `топ коины`, `топ активности`, `топ неделя`, `топ месяц`) render a fresh card with the current user's position, current coins/messages and a live top-three podium. Rank accents are gold for #1, silver for #2, bronze for #3, and blue-violet for other positions. Cards are generated at runtime by `app/chat_rank_card.py`; the generated temporary PNG is removed after sending.
